# cancer-cell-detection-and-classification
Repo to hold code and related materials for dissertation 'Detection and Classification of Cancer Cells in Breast Ultrasound Images'.

## Data Preprocessing Pipeline
to run:
1. activate conda env built from `./environment.yml`
2. from root directory run `./src/data/run.py`
3. all processed data will be saved to './data/processed/`

## Model Training
1. run `./src/models/run_training.py` and follow terminal instructions
